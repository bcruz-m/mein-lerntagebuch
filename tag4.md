# Building and Deploying a Movie Finder

## What I learned
I built a Movie Finder using Next.js, TypeScript and the TMDB API.

The application allows users to search for movies and was later extended with multilingual support in English, Portuguese and German.

I also learned how to move a project from local development to GitHub and deploy it with Vercel.

## Problem
The application depended on an external API and required the correct API credentials and environment configuration before it could work properly.

I also needed to make sure the deployed version worked outside my local environment.

## How I solved it
I configured the required environment variables, tested the movie search locally and then pushed the project to GitHub.

After deploying it with Vercel, I tested the live version and updated the README with the project information.

This was my first experience taking an application through the complete workflow from development to a publicly accessible deployment.
