# Working with an API

## What I learned
I learned the basic concept of retrieving information from an external API and working with JSON data.

Using the Open Beauty Facts API, I worked with an endpoint, sent a GET request and identified useful fields in the returned data.

## Problem
At first, the API response contained much more information than I actually needed, which made it difficult to understand what was relevant.

## How I solved it
I inspected the JSON structure and focused only on the fields required for the exercise.

I also experimented with using Claude to help generate a small Python implementation.

This helped me understand how applications can use external data instead of storing everything themselves.
