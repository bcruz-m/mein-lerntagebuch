# Building My Personal Website

## What I learned
I learned how to turn an idea and a set of requirements into a working website using AI-assisted development.

Before building, I defined the content, structure and visual direction of the site. I then used Lovable to create the website and iterated on the result.

## Problem
The first generated versions did not always match the visual style, content or layout I had in mind.

## How I solved it
I became more specific in my prompts and changed one element at a time instead of asking for many changes at once.

I also tested the result on different screen sizes and refined the website through several iterations.

This taught me that AI-generated applications still require clear requirements, testing and human decisions.
