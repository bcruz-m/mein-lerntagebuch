# My Developer Learning Diary

This repository documents seven learning milestones from my Vibe Coding Bootcamp.

The entries were added retrospectively and are based on projects, exercises and challenges I actually worked on during the bootcamp.

Each entry focuses on:
- What I learned
- A problem or challenge I encountered
- How I solved it

## Learning Diary

1. Development Environment & Git Setup
2. Building My Personal Website
3. Working with an API
4. Building and Deploying a Movie Finder
5. User Research & Product Validation
6. From Assumptions to a UX Briefing
7. Pack & Go – Building a First Prototype

The diary shows my progression from setting up development tools and building small applications to researching, validating and prototyping my own product idea.
