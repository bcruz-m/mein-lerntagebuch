# Development Environment & Git Setup

## What I learned
I learned how the different tools in a development environment work together, including VS Code, Node.js, npm, Git and GitHub.

I also learned the basic Git workflow: creating a repository, tracking changes, committing them and pushing them to GitHub.

## Problem
While setting up one of the projects, I encountered dependency conflicts when installing packages.

## How I solved it
I checked the error messages and used `--legacy-peer-deps` to resolve the dependency conflict.

This helped me understand that setup errors are part of development and that reading terminal output is often the first step toward solving them.
